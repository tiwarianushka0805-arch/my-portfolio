# Personal Portfolio Website

## About the Project

This is my personal portfolio website, developed with the help of Cursor AI. It showcases my introduction, educational background, technical skills, and projects. The website also includes interactive features to improve the user experience.

## Technologies Used

- HTML
- CSS
- JavaScript
- Weather API
- AI API for the chatbot 

## Features

- **Personal Introduction:** Displays my introduction, education, and technical skills.
- **Project Showcase:** Displays my projects with descriptions and relevant links.
- **Project Search:** Allows users to search for projects by name or technology.
- **Light and Dark Mode:** Allows users to switch between themes.
- **Weather Feature:** Displays weather information using a weather service or API.
- **AI Chatbot:** Answers questions about my portfolio, skills, and projects.
- **Responsive Design:** Adapts the layout to different screen sizes.
