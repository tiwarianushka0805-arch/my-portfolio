## Features

## Setup Instructions
1. Clone this repository:
   `git clone https://github.com/YOUR_USERNAME/my-portfolio.git`
2. Open the project folder.
3. Open `index.html` in a browser, or use the Live Server extension in VS Code or Cursor.
